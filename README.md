# Portfolio

SEOYUN SHIN의 포트폴리오 사이트입니다. React + Vite로 구성되어 있습니다.

## 로컬 경로

이 저장소는 **외장 드라이브**에 있습니다.

| 항목 | 경로 |
|------|------|
| 실제 경로 | `/Volumes/SEOYUN/portfolio` |
| 편의 경로 | `~/SEOYUN/portfolio` (`~/SEOYUN` → `/Volumes/SEOYUN` 심볼릭 링크) |
| 이전 경로 | `~/Downloads/portfolio` (이전 위치, 더 이상 사용하지 않음) |

작업 전에 SEOYUN 외장 드라이브가 마운트되어 있어야 합니다.

## 개발

```bash
cd ~/SEOYUN/portfolio   # 또는 /Volumes/SEOYUN/portfolio
npm install
npm run dev
```

| 명령어 | 설명 |
|--------|------|
| `npm run dev` | 개발 서버 (http://127.0.0.1:5173) |
| `npm run build` | 프로덕션 빌드 |
| `npm run preview` | 빌드 결과 미리보기 |
| `npm run lint` | ESLint 검사 |
